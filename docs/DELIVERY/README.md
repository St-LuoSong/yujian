## 2. 交付物清单

| 交付物 | 路径 | 说明 |

| Android APK（本机联调） | `flutter build apk --debug` | 不带参数时回落 `http://10.0.2.2:8080/api`，需要本机 Spring 服务在跑 |
| Android APK（发布） | `flutter build apk --release --dart-define=API_BASE_URL=https://…` | **必须**带 HTTPS 地址；release 不内置明文回退，未配置时启动即提示配置失败 |

| 运营管理台 | `backend/admin/`（Vue 3 + Vite） | `npm run dev` 打开，浏览器访问；只做内容与运行管理，不是游客端 |
| 内容库 | 管理台"景点管理"页维护，图片走 `POST /api/admin/media` 上传 | 存储位置见 `MEDIA_BASE_URL` / `app.media.*` |
| 验证脚本 | `scripts/verify-*.mjs` | 见《测试说明》第 3 节 |
| 配图作业单 | [`配图作业单.md`](./配图作业单.md) | 景点配图的人工作业清单、图片规格与版权登记要求 |

## 3. 演示脚本

推荐演示画像：

> 两名外地游客从郑州出发，周末两天去洛阳看历史文化，预算每人 1000 元，
> 优先高铁与公共交通，节奏适中。

### 3.1 在线模式（`APP_TOOLS_MODE=live`，真数据）

| # | 操作 | 看点 |
| --- | --- | --- |
| 1 | 打开 APK，不登录浏览"发现"页 | 河南文旅内容与三条示范走廊；无强制登录 |
| 2 | 进入"龙门石窟"详情 | 图片、文化介绍、门票参考、建议时长、图片来源与数据状态标注 |
| 3 | 切到"行程"页，填条件：郑州 → 洛阳、周末、2 天、2 人、人均 1000、历史文化、轻松、高铁 | 起终点交换、中文日历、可输入天数、自定义兴趣 |
| 4 | 点"生成专属行程" | 生成管线按后端真实步骤推进，不伪造工具调用 |
| 5 | 看结果：逐日时间轴 + 四项风险核对 + 预算拆分 + 天气 + 行程强度 | "为什么这个方案走得通" |
| 6 | 切"地图" Tab | 底图由服务端代取（AK 不出服务器），标记/折线与时间轴联动 |
| 7 | 输入"第二天轻松一点，并增加当地美食" | 展示改动前后差异、费用与强度变化 |
| 8 | 点"撤销" | 回到调整前快照 |
| 9 | 看"方案依据" | 引擎、提示词版本、每个工具的来源与状态（实时/缓存/演示） |
| 10 | 保存后进"我的行程" → 行尾"更多" | 重命名、删除（删除要二次确认） |
| 11 | "今日行程" → 下一站 | 行中执行入口，显示天气与预计出发时间 |
| 12 | 生成只读分享（可隐藏预算） | 分享链接/二维码，接收者只读 |
| 13 | 断网后重进"我的行程" | 展示缓存方案并明确标注缓存状态，不白屏 |
| 14 | 打开运营管理台 | 景点管理（含图片上传、坐标、图片来源）、运行统计、工具健康度、LLM 供应商健康度、反馈与日志 |

### 3.2 稳定模式（`APP_TOOLS_MODE=mock`，断网也能讲完）

- 外部工具全部走演示数据，页面上逐条标注 `演示数据`；
- 规划仍可走真实 LLM（若已配置）或 Mock 引擎，界面上会写清楚是哪一个；
- 不可把演示数据讲成"实时"——这是全项目硬约束，演示话术也要遵守。

## 4. 一键复现（本机）

```bat
:: 1. 后端（读 scripts\local.env 里的密钥，不进仓库）
scripts\run-server-dev.cmd
::    改成用 MySQL 8（先 scripts\init-mysql.cmd 初始化一次库）
:: scripts\run-server-mysql.cmd

:: 2. 管理台
cd backend\admin && npm install && npm run dev

:: 3. APK
cd flutter_app && flutter build apk --debug --dart-define=API_BASE_URL=http://10.0.2.2:8080/api

:: 4. 自动化验证
cd backend\server && mvn -o -B test
cd ..\..\flutter_app && flutter analyze && flutter test
cd .. && node scripts\verify-tools.mjs
```
