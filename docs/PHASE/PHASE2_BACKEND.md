# 阶段二：服务端持久化、认证与业务闭环

## 已完成范围

- 用户注册、登录、刷新令牌轮换、退出与当前用户查询。
- 匿名体验会话：服务端只保存令牌哈希，默认一次规划额度，支持登录后合并行程。
- 行程持久化：行程、每日节点、数据来源、数据状态和风险提示均保存到数据库。
- 行程闭环：创建、列表、详情、修改、删除、局部调整、撤销和今日行程。
- 只读分享：分享链接、有效期、隐藏预算、访问计数与关闭分享。
- 收藏：登录用户添加、查询和删除收藏。
- SMTP 预留：验证码发送、哈希存储、有效期、发送频率、失败次数与邮箱验证。
- 安全基础设施：BCrypt、JWT、Spring Security、CORS 白名单、统一异常与资源归属校验。
- 开发环境使用 H2，本地演示不依赖外部服务；生产 profile 使用 MySQL 8。

## 本地验证结果

已使用 `mvn -DskipTests compile` 完成编译，并对以下链路做过本地 HTTP 冒烟验证：

1. 首页与景区公开接口可访问。
2. 匿名会话创建成功。
3. 未登录创建行程成功，响应头返回 `X-Anonymous-Token`。
4. 匿名行程列表、调整、撤销、今日行程正常。
5. 匿名试用额度第二次触发 `429 TRIAL_LIMIT_REACHED`。
6. 未登录访问受保护列表返回 `401`。
7. 注册、登录、`/api/auth/me`、刷新令牌轮换、退出后刷新失败均符合预期。
8. 登录后合并匿名行程成功。
9. 收藏添加与查询成功。
10. SMTP 关闭时返回 Mock 验证码，验证成功；生产 profile 已禁止调试验证码。
11. 分享链接可访问，隐藏预算后金额为 0。
